# 微信收款二维码配置

将管理员确认使用的微信收款二维码保存为：

```text
public/payment/wechat-qr.png
```

前端会自动从 `/payment/wechat-qr.png` 加载该图片。图片不存在或无法加载时，升级弹窗会显示“微信收款二维码待配置”。以后更换收款码只需要替换这张图片，不需要修改前端或会员开通逻辑。

`wechat-qr.png` 默认被 `.gitignore` 忽略，不得提交到 GitHub。部署时应通过部署平台的私有文件、挂载目录或构建环境单独放入真实二维码。仓库中只保留本说明和前端的安全占位状态；不要使用 `git add -f` 强制提交真实二维码。

不要在此目录或二维码旁保存微信 Cookie、Token、数据库密码、API Key 或其他私人凭证。
