# Local portrait segmentation model

`selfie.json` and `selfie.bin` are the lightweight MediaPipe Selfie Segmentation
model distributed by the Human Models project:

- Source: https://github.com/vladmandic/human-models
- Revision: `bc66dc53bac03c96d35a7e6daaf717e72f3985f5`
- License: MIT, copyright Vladimir Mandic

The two files are intentionally stored with the backend so production does not
download a model from a CDN and does not require an API key.
